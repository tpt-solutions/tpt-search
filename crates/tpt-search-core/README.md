# tpt-search-core

Core types for `tpt-search`: documents, schemas, text analysis, the error hierarchy, and async and telemetry helpers shared by every other crate.

> **Status:** Pre-release (0.1.0), not yet published to crates.io. Part of [tpt-search](../../README.md).

## Features

- Documents and schemas (`document`, `schema`)
- Text analysis and stemming via `rust-stemmers` (`analysis`)
- Error hierarchy built with `thiserror` (`error`)
- Async runtime helpers (`runtime`) and `tracing`-based telemetry (`telemetry`)
