# tpt-search-graph

Graph search for `tpt-search`: a directed property graph, traversal (BFS, DFS, shortest paths), graph analytics, and a Cypher-style pattern language. Node ids match document ids in the search layer.

> **Status:** Pre-release (0.1.0), not yet published to crates.io. Part of [tpt-search](../../README.md).

## Features

- Directed property graph (`graph`)
- BFS, DFS and shortest-path traversal (`traversal`)
- Analytics: connected components, PageRank, betweenness centrality, label propagation (`analytics`)
- Cypher-style pattern matching with a match cap (`pattern`)
